# Completed tasks

Finished queue items, most recent first. When an item in `docs/next-steps.md` is done, it moves here:
the date, what was asked, what was done, what was confirmed and on which build (statically or by
execution), the commits, and where the evidence is (`data/resolved-<v>.json` provenance, the findings
doc). The queue keeps only open items, so this log is where a finished item's history is looked up.

This published repository starts with an empty log. The work up to its first commit is recorded in the
findings docs and in the provenance of `data/resolved-<v>.json`.
